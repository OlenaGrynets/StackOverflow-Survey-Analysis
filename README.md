# StackOverflow-Survey-Analysis

## Dataset

Source: Stack Overflow Developer Survey 2025

The dataset is publicly available at:
https://survey.stackoverflow.co/2025/

Download the following files and place them into the `data` folder:
- survey_results_public.csv
- survey_results_schema.csv

## Tools: Python, Pandas
- Analyzed salary, technology, and labor market trends
- Processed large-scale survey data
- Delivered statistical insights and visualizations
